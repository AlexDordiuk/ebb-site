# Ebb site

Home page, guides, Privacy Policy and Support pages for the Ebb iOS app, served by GitHub Pages:
https://alexdordiuk.github.io/ebb-site/

- Home pages and guides (`index.html`, `uk/index.html`, `guides/…`, `sitemap.xml`, `robots.txt`) are generated by
  `ebb-ios/site/build.py` from sources in the private `ebb-ios/site/src`. Edit them there and rebuild.
- `privacy/`, `support/`, `uk/privacy/`, `uk/support/` are hand-written.
- Swedish, Norwegian and Danish pages are drafts until a native speaker reviews them; `.gitignore` keeps them out.
- All links are relative. To move to a custom domain or another host, change `base_url` in `ebb-ios/site/src/site.json`
  and rebuild.
